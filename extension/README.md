# يقين: إضافة المتصفح

إضافة لمتصفحي Chrome وEdge تفحص منشورات X وFacebook وTikTok أثناء التصفح، وتطابق الآيات والأحاديث مع المصادر المعتمدة في ملف المراجع فقط، ثم تعرض أحد هذه التصنيفات بجانب المنشور:

| التصنيف | ما يُعرض |
|---|---|
| مطابق لنص المصحف | اسم السورة ورقم الآية، ونص المصحف |
| حديث ثابت | الحكم ومن حكم به والمرجع |
| ورد بلفظ مختلف | اللفظ الصحيح من المصدر مع زر نسخ للمشاركة |
| ضعيف أو موضوع | حكم العلماء كما ورد، مع المرجع |
| اختلف العلماء في الحكم عليه | كل حكم مع صاحبه ومرجعه، دون ترجيح |
| لم نعثر على المصدر | عبارة محايدة بأن النص غير موجود في مصادرنا (وليست حكمًا عليه) |

الأداة لا تكتب أي حكم من عندها: كل تصنيف مبني على حقول السجل في المصدر نفسه، وكل بطاقة تذكر أنها نتيجة آلية وليست فتوى.

## المصادر (من ملف المراجع المعتمد فقط)

| الغرض | المصدر | أين يعمل |
|---|---|---|
| نص القرآن وترجمة المعاني الإنجليزية | موسوعة القرآن الكريم quranenc.com | يُنزّل مرة واحدة ويُطابق على الجهاز |
| الأحاديث الثابتة | موسوعة الأحاديث النبوية hadeethenc.com | يُنزّل مرة واحدة ويُطابق على الجهاز |
| الحكم على الأحاديث، والضعيف والموضوع | الموسوعة الحديثية في الدرر السنية dorar.net | عبر الإنترنت، فقط للحديث غير الموجود محليًا، ويُرسل نص الحديث وحده |

## كيف يعمل

1. **الاكتشاف:** يقرأ نص المنشور ويقسمه إلى مقاطع (ما بين ﴿ ﴾ وعلامات التنصيص، والأسطر، والمنشور كاملًا).
2. **OCR:** عند الضغط على "فحص النص في الصورة" يُستخرج النص على الجهاز بـ Tesseract (عربي وإنجليزي).
3. **التطبيع:** حذف التشكيل وعلامات الرسم العثماني وتوحيد الألف والياء والتاء المربوطة، ثم "هيكل" بلا ألفات ومسافات حتى يتطابق الرسم العثماني مع الإملائي.
4. **المطابقة:** استرجاع سريع بمقاطع الحروف، ثم مطابقة تقريبية (مسافة التحرير) تجد الآية حتى لو كانت جزءًا من منشور طويل أو ممتدة على أكثر من آية.
5. **المطابقة الدلالية:** نموذج تضمين متعدد اللغات (multilingual-e5-small) يعمل على الجهاز ويُستخدم فقط عندما يكون التشابه الحرفي متوسطًا، لاكتشاف النص المنقول بمعناه.
6. **التصنيف:** بقواعد ثابتة من بيانات المصدر.

## الخصوصية

- المطابقة مع القرآن والأحاديث المنزّلة تتم على الجهاز.
- استخراج النص من الصور على الجهاز، وعند الضغط فقط.
- للدرر السنية يُرسل نص الحديث المستخرج فقط، دون رابط الصفحة أو أي بيانات عن المستخدم، ويمكن إيقافه من الإعدادات.
- إذا تعذّر الوصول للدرر لا تُعرض "لم نعثر على المصدر"، بل "تعذر الفحص الآن"، حتى لا يُفهم غياب الاتصال على أنه غياب المصدر.

## التشغيل

```bash
cd extension
npm install --ignore-scripts
npm test          # اختبارات المطابقة والتصنيف
npm run build     # يبني الإضافة في dist/
```

ثم افتح `chrome://extensions` (أو `edge://extensions`)، فعّل وضع المطوّر، واختر **Load unpacked** ثم مجلد `extension/dist`. ستفتح صفحة الإعدادات، اضغط **تنزيل البيانات الآن**.

## هيكل الكود

```
src/core/        التطبيع، الاكتشاف، المطابقة، قراءة أحكام العلماء، التصنيف (بدون أي اعتماد على المتصفح)
src/sources/     عملاء QuranEnc وHadeethEnc والدرر السنية
src/background/  عامل الخدمة: الفهارس، التنزيل، الفحص
src/offscreen/   OCR ونموذج التضمين
src/content/     حقن الشارات في X وFacebook وTikTok
src/ui/          بطاقة النتيجة بألوان تصميم Figma
src/options/     الإعدادات والخصوصية
src/popup/       فحص نص يدويًا
test/            اختبارات (vitest)
```

## نقاط تحتاج مراجعة

- **جدول قراءة الأحكام** في `src/core/grades.ts` يربط ألفاظ العلماء (صحيح، حسن، ضعيف، منكر، موضوع، لا أصل له...) بالتصنيف. يحتاج مراجعة شرعية قبل الإطلاق.
- الحكم الذي لا يطابق أي لفظ في الجدول يُعرض كما ورد تحت "أحكام العلماء كما وردت في المصدر".
- موسوعة الأحاديث النبوية تنشر الحكم والتخريج (مثل: صحيح، متفق عليه) ولا تنشر اسم عالم بعينه.
- حدود التشابه في `THRESHOLDS` داخل `src/core/checker.ts` مبدئية، وتحتاج معايرة على مجموعة أمثلة حقيقية.
- واجهات المصادر لم تُجرَّب مباشرة من بيئة البناء لأن الشبكة فيها محجوبة؛ صيغة ردود الدرر مأخوذة من النموذج الأولي في هذا المستودع.
- محددات عناصر الصفحة في `src/content/platforms.ts` قد تتغير مع تحديثات المواقع، وTikTok يُفحص فيه الوصف والتعليقات وصور منشورات الصور فقط، لا إطارات الفيديو.

# Yaqeen browser extension (English)

A Chrome/Edge (Manifest V3) extension that checks Quran verses and hadith in X, Facebook and TikTok posts against the approved sources only (QuranEnc, HadeethEnc, Dorar), and shows one of: matches the Quran text, authentic hadith, reported with different wording, weak or fabricated, scholars differed, or source not found. Quran and HadeethEnc matching, OCR and the embedding model all run on the device; only the extracted hadith text is sent to Dorar when it is not found locally. Build with `npm install --ignore-scripts && npm run build`, then load `extension/dist` as an unpacked extension.
